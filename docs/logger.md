# Validation Logger

## Purpose

The Validation Logger records every battery update for debugging and
validation.

---

## Logged Parameters

Time

SOC

Voltage

Current

Power

Temperature

ETA

Status

---

## Warning Levels

Battery Low

Battery Critical

Simulator Started

Simulator Stopped

---

## Output

logs/battery.log

---

## Example

2026-07-17 18:20:10

SOC = 92 %

Voltage = 16.3 V

Current = 2.5 A

Status = GOOD
