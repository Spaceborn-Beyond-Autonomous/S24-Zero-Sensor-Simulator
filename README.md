# 📖 Overview

The **S24 Zero Sensor Simulator** is a ROS 2 package that simulates multiple sensors for autonomous robots.

It enables developers to develop, test, and validate robotics software before physical hardware becomes available.

The simulator provides realistic dummy data through ROS 2 nodes and supports a modular architecture that allows new sensors to be added easily.

# ▶ Run Individual Nodes

Battery

```bash
ros2 run s24_zero_sensor_simulator battery_node
```

Camera

```bash
ros2 run s24_zero_sensor_simulator camera_node
```

LiDAR


IMU


GPS

